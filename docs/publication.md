# Publication Checklist

This snapshot excludes the original Git history, unrelated presentations, Power BI
material, contract documents, historical compiler/simulator implementations and the
separate SDP-META fork. The original repository remains a backup, unchanged by the
new repository's history.

Before changing visibility to public:

- Review all tracked files and the initial commit, not just the working directory.
- Repeat secret scanning and inspect fixtures for real customer or employee data.
- Confirm rights to publish the code and choose a license explicitly.
- Review GitHub Actions logs, repository settings and any future issues/artifacts.
- Confirm no private workspace identifiers or credentials were added during testing.

Only synthetic sample data belongs here. No open-source license or regulatory
endorsement is implied by creating this private repository.
